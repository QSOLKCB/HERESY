# HERESY Manifesto — The Useful Software Incident

> **CI passed. The industry has opened a centre of excellence to investigate.**

HERESY is an anthology of technically real, reproducible offences against
architectural fashion.

## Article I — The heresy must execute

Dead-language wallpaper is not enough. Every historical boundary must
materially affect program output and be covered by deterministic proof.

## Article II — Useful software is the sharper protest

It is easy to make a tiny joke program. v4 must remain genuinely useful:
offline, accessible, understandable, exportable and capable of applying its
architecture budget to a real product brief.

## Article III — Complexity must face the user

Technology is not convicted merely for being new. Every dependency, service,
control plane and meeting must answer: which user problem requires you?

“Industry standard” is not an answer. It is a witness asking for counsel.

## Article IV — The database shall be beige

v4 stores every completed run in the `RUN-RECORD` declared by actual COBOL.
Each row is 379 characters. Every field is padded to its `PICTURE` clause.
Every record is checksummed. JSON, SQL and the ORM are excused from the
building.

The browser provides a virtual disk. COBOL provides certainty, column widths
and the vague feeling that payroll is nearby.

## Article V — The budget is physical

The complete production application receives 128 KiB, matching the original
128K Macintosh. There is no build tool to erase the evidence and no minifier
to compress a dependency graph into moral ambiguity.

## Current offence: v4.0.0

```text
small production brief
  -> modern architecture decisions
     -> COBOL scoring records
        -> useful consequence budget
           -> COBOL fixed-record database
              -> portable architecture receipt
```

The simulator tracks payload, dependencies, cold start, cloud cost, risk,
meetings, delivery time, user value and résumé value. A custom mode makes it a
practical workshop instrument. The satire is optional; the arithmetic is not.

## Preserved offence: v3.0.0

Cloud-native microservices on an EBCDIC punch card lives under
`editions/v3-cloud-native-punch-card/`. JCL authorises a shuffled card deck;
COBOL defines it; EBCDIC encodes it; FORTRAN routes it; Ada assumes missiles.

## Preserved offence: v2.0.0

React inside Commodore BASIC inside React lives under
`editions/v2-react-in-basic-in-react/`. BASIC `DATA` bytes reconstruct the
specification for an inner React component because direct component creation
lacked theological depth.

## Preserved offence: v1.0.0

C inside Rust inside C lives under `editions/v1-c-in-rust-in-c/`. Rust embeds
and compiles a C generator; that generator writes, compiles and links another C
project. The original Zenodo DOI remains `10.5281/zenodo.17588734`.

## Future violations

Future editions must preserve every previous offence, state exactly what
executes, and remain more disciplined than the architecture they mock.
