# HERESY v3.0.0 — Cloud-Native Microservices on an EBCDIC Punch Card

This directory preserves the complete v3 root edition before HERESY v4 replaced
it as the anthology's main offence.

The byte-for-byte historical snapshot is under [`original/`](original/). It is
still runnable:

```sh
cd original
npm ci
npm run dev
```

Complete verification:

```sh
npm run check
```

The snapshot contains the original source, locked dependency graph, CI
workflow, JCL, COBOL, FORTRAN, Ada, citation metadata, manifesto and 360 KB
floppy size gate.

> “I routed the cloud-native microservice through an EBCDIC punch card because
> JSON lacked institutional trauma.”
