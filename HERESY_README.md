# THE AI/1440 MANIFESTO

Modern AI systems can require tens of gigabytes of model artifacts to answer a five-line mathematics exam, then add a second system to explain what the first system said, a third system to monitor the explanation, and a fourth system to invoice the other three.

HERESY AI/1440 objects by putting the evidence layer on a floppy.

## Article I — Evidence is not infrastructure

A recorded answer has bytes. Hash the bytes. Keep the prompt. Keep the model identifier. Keep the runtime provenance. Do not replace a missing fact with an interpretive flourish because the dashboard looked lonely.

## Article II — The model is not on the floppy

The production artifact is a governance appliance, not a compressed miracle. Model weights stay outside. Imported WHOAMI receipts come inside. The distinction is written down because eventually somebody in a meeting will ask whether the 1.44 MB disk contains GPT.

It does not.

Management has been informed.

## Article III — Zero parameters may still be useful

HERETIC-0 is not an LLM. It has no weights, no sampling temperature, no latent representation and no opinion about its own benchmark performance. It can nevertheless reject a fabricated premise, decline to invent an unknown identity and execute the fixed mathematics required by the control battery.

The point is not that deterministic software is generally smarter than learned models. The point is that some tasks do not require stochastic completion at all.

## Article IV — The parent shall be deterministic

PARENT-0 contains explicit rules, explicit state and zero randomness.

It asks why you will not study.
It asks why you used a tool when the book was available.
It notes that 93.8% leaves 6.2% mysteriously unattended.
It receives 100% and immediately asks why there was no extra credit.

This is original software satire inspired by the era of rule-based talking programs. It is not Dr. Sbaitso and does not copy Dr. Sbaitso dialogue.

The parent has zero parameters and unbounded expectations. This imbalance is considered stable.

## Article V — If a model receives the lecture, preserve the lecture

The optional local Ollama lab sends exactly the same fixed PARENT-0 sequence to every selected model. Visible replies are hashed. The canonical transcript is hashed. The human-facing transcript is written to `LECTURE.md` so a reader can inspect what actually happened instead of trusting a graph called Engagement Intelligence.

No live reply may be invented merely to make the repository more entertaining.

## Article VI — Metadata is not destiny

Country and origin labels may organize a model roster. They do not explain model behavior. HERESY records bounded surface responses under fixed prompts and refuses to promote those observations into claims about culture, ethnicity, nationality, psychology, developer populations, family histories, training corpora or RLHF transfer.

Satire may be rude to architecture. Evidence must remain polite to causality.

## Article VII — The vector database shall fit in a file

The retrieval engine tokenizes evidence, constructs sparse term-frequency vectors and uses deterministic cosine similarity. There is one shard because there is one file. There are zero replicas because the test suite already exists.

If a query has no evidence match, the system says so.

This feature is also known as not lying.

## Article VIII — The floppy shall boot

The image is not a renamed ZIP and not a decorative binary blob. It has a standard FAT12 BIOS Parameter Block, two FATs, the standard 1.44 MB geometry, a root directory, a `55 AA` signature and 16-bit x86 boot code.

On boot it reports that the model weights were denied boarding.

This is technically unnecessary and therefore essential.

## Article IX — Every byte faces architecture review

The production evidence image is exactly 1,474,560 bytes. Fixed timestamps and canonical ordering make repeated builds byte-for-byte identical.

No package manager is needed to build it. No cloud account is needed to use it. No telemetry endpoint waits for the user to become interesting.
